# ddworkin.github.io

Privacy policies and support pages for David Dworkin's apps, served by GitHub Pages at
https://ddworkin.github.io. One folder per app (`/<app>/privacy/`, `/<app>/support/`), shared
styles in `assets/site.css`. `.nojekyll` serves the files as-is.

When an app's data practices change, update its privacy page (and effective date) before that
version ships, and keep it matching the App Store privacy label.
